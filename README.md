🐶 The Beagle Blog
📘 Project Overview

The Beagle Blog is a simple HTML and CSS project that showcases information about the Beagle dog breed.
It includes descriptive content, images, trivia, and reference links — all styled to match a clean, bordered layout similar to the given Figma design.

🧩 Features

📰 Top Section: Contains a short description about the Beagle and a “Read More” link to Wikipedia.

🖼️ Image Section: Displays a Beagle image and a “More Images” link to Google Images.

📋 Trivia Section: Lists interesting facts about the Beagle in an ordered list format.

🎨 Styled Layout: Simple bordered layout, underlined headings, and readable typography.

🌐 Deployed Online: Easily hostable via GitHub Pages.
